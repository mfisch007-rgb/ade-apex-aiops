# Development Workflow

## Git Strategy

main
↓

develop
↓

feature/*

Every feature is developed on its own branch.

Every Engineering Pack is committed as a logical unit.

Every Pull Request must be reviewed before merge.

## Development Order

1. Architecture
2. Contracts
3. ADRs
4. Scaffolding
5. Implementation
6. Tests
7. Deployment

## Quality Gates

- Lint
- Unit Tests
- Security Scan
- Contract Validation
- Documentation Review
